Little Genius Kids — Fun Zone upgrade

Adds five offline mini-games: Bubble Pop, Rainbow Drawing, Music Maker, Sticker Garden, and Move & Smile. English, Gujarati and Hindi UI. Existing learning games and voice settings are unchanged.

To update GitHub Pages:
1. Back up your existing repository via Code > Download ZIP.
2. In the root of the repository, Add file > Upload files.
3. Upload index.html, app.js, fun-zone.js, sw.js (replace existing names).
4. Commit directly to main. Keep manifest.webmanifest and icons unchanged.
5. Wait for GitHub Pages deployment, reload the live site. On an installed PWA, close/reopen or refresh to pick up the new offline cache.

Note: This version uses no external services, recordings or ads. Music plays only after a tap; Safari/Android may require sound to be enabled.
